# Trop lent pour l'instrument

> 30 octobre 2026 — Mathieu Guglielmino

Ouvrir `index.html` et suivre vers l'application. L'application charge la bibliothèque partagée `/assets/dossier-app.{js,css}` : elle se consulte servie par le site, pas en `file://`.
