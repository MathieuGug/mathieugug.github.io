# La salle blanche ne prouve rien

> 19 août 2026 — Mathieu Guglielmino

Dossier de recherche illustré sur les salles blanches de données et ce qu'elles peuvent, ou ne peuvent pas, établir pour une direction data.

**Thèse.** La salle blanche a été vendue comme le lieu où la mesure redevient vérifiable. Le mécanisme qui empêche d'y ré-identifier un individu est celui qui empêche d'y auditer le chiffre qui sort, et cette exclusion n'est pas un défaut de produit : c'est un théorème. Google l'écrit lui-même en excluant le mode bruité du périmètre accrédité d'Ads Data Hub. Une salle blanche est un lieu d'opération, pas un lieu de preuve.
