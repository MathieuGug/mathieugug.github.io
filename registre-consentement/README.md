# Une bannière n'est pas une preuve

> 30 septembre 2026 — Mathieu Guglielmino

Dossier approfondi sur les trois registres du consentement : le **choix** (par utilisateur, dans la plateforme de recueil), la **preuve** (les versions successives de ce qui était affiché et configuré), la **série** (les taux datés).
