# Le palier qu'on ne peut pas vérifier

> 2 octobre 2026 — Mathieu Guglielmino

Dossier approfondi sur les échelles d'autonomie agentique publiées, et sur la variable qu'elles devraient graduer.

**Thèse.** Quatre cadres publiés graduent l'autonomie des agents sur trois variables incompatibles, et une seule se vérifie : la réversibilité de l'acte.
