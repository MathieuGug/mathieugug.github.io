# Ce que l'agent ne peut pas deviner

> 11 septembre 2026 — Mathieu Guglielmino

Dossier sur le socle data prêt pour l'agentique. Thèse : un agent d'analyse échoue sur ce que personne n'a écrit ; préparer le socle consiste à convertir les erreurs silencieuses en erreurs bruyantes, et aucun taux d'exactitude publié par un éditeur ne prédit celui qu'on obtiendra chez soi.

## Contenu du dossier

| Fichier | Rôle |
|---|---|
| `index.html` | Hub d'entrée du dossier |
| `20260911-socle-semantique-app.html` | Application illustrée — 9 sections, 7 schémas interactifs, 31 régions cliquables, 13 sources, glossaire au survol |
| `20260911-socle-semantique-rapport.md` | Rapport markdown (compatible Obsidian), notes de bas de page numérotées |
| `images/` | Les 7 schémas éditoriaux en SVG |

L'application s'ouvre directement dans un navigateur, sans serveur ni étape de construction. Elle charge `/assets/dossier-app.css` et `/assets/dossier-app.js` depuis la racine du site.

## Les sept schémas

1. Cinq mesures du même effet, cinq mondes différents
2. Le même modèle, trois patrimoines
3. Trois classes d'erreur, rangées par le bruit qu'elles font
4. Ce que la couche sémantique déplace
5. Les trois états d'une définition métier
6. Le filtre a changé d'étage
7. Six décisions, classées par ce qu'elles rendent bruyant

## Réserves de sourçage

Les chiffres d'exactitude publiés par des éditeurs sur leurs propres produits sont annoncés et non audités ; ils sont utilisés pour leur dispersion et non pour leur valeur. Plusieurs domaines ont été refusés par le relais réseau utilisé pour la rédaction — le détail figure dans la note de méthode du rapport.
