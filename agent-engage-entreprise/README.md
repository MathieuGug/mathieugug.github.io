# Quand un agent engage l'entreprise

> 7 août 2026 — Mathieu Guglielmino

Dossier de recherche illustré sur la responsabilité du déployeur d'un agent conversationnel : ce que douze incidents datés ont réellement établi, et pourquoi le risque de 2026 est probatoire avant d'être juridique.

**Thèse.** Le droit n'avait pas de trou : chaque incident documenté depuis 2023 a été tranché avec les règles ordinaires, et toutes disent que la parole de l'agent est la parole de celui qui l'a déployé. Ce qui bascule en 2026 est ailleurs — la directive (UE) 2024/2853 attache une présomption de défectuosité à l'incapacité de produire les éléments demandés, pendant que les exclusions d'assurance visant l'IA générative referment la voie du transfert de risque.
