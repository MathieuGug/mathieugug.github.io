    Statut du registre : préversion depuis le 8 septembre 2025, gel d'interface v0.1 le 24 octobre 2025. Décrit aussi la preuve de propriété de l'espace de noms, seul signal d'appartenance disponible.

    Définit les trois états (active, deprecated, deleted), le message d'accompagnement plafonné à 500 caractères, et le tri des versions comme chaînes de caractères — le piège qui fait prendre le premier résultat pour la dernière version.

  • github.com/modelcontextprotocol/registry « Ecosystem vision » du registre officiel

    La source qui autorise la thèse du dossier : le registre officiel est un métaregistre centré sur « la découvrabilité et les métadonnées de base », et la curation est explicitement renvoyée aux sous-registres. Le catalogue d'entreprise en est un.

  • github.com/modelcontextprotocol Spécification 2026-07-28, section « Tools »

    Le modèle de données d'un outil et la phrase charnière : les clients doivent considérer les annotations comme non fiables sauf si elles proviennent de serveurs de confiance — notion que la spécification ne définit nulle part.

  • invariantlabs.ai « GitHub MCP Exploited: Accessing private repositories via MCP » (mai 2025)

    L'incident qui déplace la frontière de confiance : l'instruction malveillante était dans une donnée rapportée par un outil non compromis. Les auteurs qualifient le problème d'architectural, et non de défaut de code corrigeable côté serveur.

  • blog.modelcontextprotocol.io « Beta SDKs for the 2026-07-28 Specification Release Candidate »

    Le détail proposition par proposition : validation obligatoire de l'émetteur (RFC 9207), liaison des identifiants client à leur émetteur, schémas d'outils en JSON Schema 2020-12, états du cycle de vie et liste des fonctionnalités retirées.

  • ai-act-service-desk.ec.europa.eu Règlement sur l'IA, article 26 — obligations des déployeurs de systèmes à haut risque
